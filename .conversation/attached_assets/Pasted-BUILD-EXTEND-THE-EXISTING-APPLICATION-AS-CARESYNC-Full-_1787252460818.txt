↓

↓

↓

↓

- prescribe medicine
- change treatment
- modify doctor consultation notes

============================================================
IMPORTANT IMPLEMENTATION RULE
============================================================

Do not build disconnected mock pages.

All major modules must share the same underlying patient, user, appointment, consent, healthcare journey, payment and organization data model.

If a doctor uploads a consultation:

The patient journey must update.

If a lab uploads a report:

The patient journey and relevant doctor's view must update.

If a pharmacy processes an order:

The patient pharmacy/order history must update.

If a patient grants consent:

The doctor should gain access according to the granted scope.

If consent is revoked:

The doctor should lose access where applicable.

If an appointment is booked:

It must appear in both relevant dashboards.
